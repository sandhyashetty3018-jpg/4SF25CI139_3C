# Retail Store Sales Analysis

## Project Overview
This project analyzes retail store sales data using Python and Pandas. It focuses on data transformation, missing value handling, insight generation, and visualization.

## Dataset
- Dataset: Retail Store Sales
- Records: 12,575
- Columns: 11
- Format: CSV

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Tasks Performed
1. Dataset selection and reading
2. Data understanding
3. Data transformation
4. Null value handling
5. Insight generation
6. Data visualization

## Visualizations
- Category-wise sales bar chart
- Payment method donut chart
- Quantity vs Total Spent scatter plot

## Conclusion
This project demonstrates data cleaning, transformation, analysis, and visualization using Python to understand retail store sales performance.
